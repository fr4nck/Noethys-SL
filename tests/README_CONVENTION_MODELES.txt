Recette manuelle Windows attendue avant fusion :
1. Ouvrir une famille puis Générer une convention.
2. Sur une base sans modèle Convention, vérifier l'installation automatique des exemples et la sélection visible d'un modèle.
3. Gérer les modèles > Installer les modèles d'exemple : aucun doublon, modèle scolaire présent.
4. Dupliquer un modèle, le renommer, le définir par défaut, fermer/réouvrir : sélection par défaut conservée.
5. Modifier la copie dans Noedoc, enregistrer un changement de texte, rouvrir et vérifier sa persistance.
6. Supprimer la copie : objets associés supprimés ; un autre modèle reste sélectionnable.
7. Générer un PDF associatif puis un PDF scolaire.
8. Vérifier que le dialogue conserve son comportement responsive sur petit écran.

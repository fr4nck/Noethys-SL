Noethys SL - profil portable
============================

La présence de ce dossier "Portable" active le mode portable : Noethys SL
enregistre ici sa configuration (Config.json, Customize.ini), ses fichiers
locaux (Data) et ses fichiers temporaires (Temp), au lieu du profil Windows
de l'utilisateur.

- Ne supprimez pas ce dossier : sans lui, Noethys SL utiliserait le profil
  Windows (%APPDATA%) et ne retrouverait pas la configuration portable.
- Pour changer de version, copiez ce dossier "Portable" dans le dossier de la
  nouvelle version, Noethys SL fermé.
- Ce dossier peut contenir des paramètres de connexion à la base réseau :
  ne le partagez pas et ne le placez pas sur un support non protégé.
